# Усмішка+ — Стоматологічна клініка

Односторінковий сайт-візитка стоматологічної клініки. Статичний HTML/CSS/JS, без збірки та залежностей.

## Структура

- `index.html` — розмітка сторінки
- `css/styles.css` — стилі
- `js/script.js` — мобільне меню та форма запису

## Локальний перегляд

```
python3 -m http.server 8000
```

Потім відкрити `http://localhost:8000`.

## Деплой

Сайт деплоїться на Vercel автоматично при push у гілку `main`.
